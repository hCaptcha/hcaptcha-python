# Security Policy

Do not report security issues in public GitHub issues.

## Security Bugs

We are always interested in receiving reports of security bugs.

Email **support@hcaptcha.com** and CC **security@hcaptcha.com**, and we will get back to you quickly.

Include:

- Steps to reproduce the issue
- The security impact of the issue
- The affected version(s), if applicable

We also have a bug bounty program for eligible security reports on the hCaptcha service and related source code. See <https://www.hcaptcha.com/reporting-bugs> for details.

## Privacy Issues

If you have found an issue that you think could affect user privacy, please email **support@hcaptcha.com**.

## Functional Issues

For functional (non-security) issues, open an issue in the GitHub repository: <https://github.com/hCaptcha/hcaptcha-python/issues>.
